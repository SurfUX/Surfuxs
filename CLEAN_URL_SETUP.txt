SURFUX CLEAN URL - HOSTINGER

This version uses a Hostinger-compatible .htaccess file.

Examples:
  /index.php       -> /
  /pages/about.php -> /pages/about
  /pages/news.php  -> /pages/news

IMPORTANT:
- Upload .htaccess to the SAME folder as index.php.
- Do not rename or delete the PHP files.
- This version intentionally does NOT use "Options -MultiViews",
  because some hosting configurations return HTTP 500 for that directive.
- If an old redirect is cached, test in an incognito/private window.
